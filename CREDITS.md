# Credits

## Prior art

Loadly is an independent implementation written from scratch. Its debt is to
**SpinKit** by Tobias Ahlin, which established the pattern of small,
dependency-free CSS spinners and made it popular.

- SpinKit: https://github.com/tobiasahlin/SpinKit
- Licence: MIT, Copyright (c) 2020 Tobias Ahlin

No SpinKit code is copied here. The overlap is conceptual - CSS keyframes on
`transform` and `opacity` are the only sensible way to animate a spinner, so
similar shapes are convergent rather than borrowed.

Where a Loadly spinner is a deliberate reinterpretation of a SpinKit classic,
the spinner's file notes it.
